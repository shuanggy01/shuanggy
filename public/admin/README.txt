ASUPANLENDIR - ADMIN MOBILE UI V1

Prototype dashboard mobile-first premium.
Dashboard lama TIDAK ditimpa.

PASANG:
1. Upload ZIP ke /www/wwwroot/asupanlendir.sbs/
2. Extract langsung di root project.
3. Terminal:
   cd /www/wwwroot/asupanlendir.sbs
   php -l public/admin/mobile.php
4. Buka dari HP:
   https://asupanlendir.sbs/admin/mobile.php

FITUR:
- Graphite + soft gold palette
- SVG line icons
- 4 kartu statistik
- Quick Actions
- Video terbaru model card mobile
- Album terbaru
- Bottom nav: Home / Video / Album / Ads / More
- More sheet: Analytics / SEO / Settings / Mirrors / Website / Logout

AMAN:
- Tidak mengubah database
- Tidak mengubah Telegram Bot
- Tidak mengganti dashboard lama
- Tidak mengubah Ads/SEO/Settings

Kalau desain cocok, V2 akan menjadikan shell ini dasar untuk Video Manager mobile dan halaman admin lain.
